# Enuexus

A landing page for a fraud-intelligence company, built with HTML and CSS.

**Live demo:** https://muhammadrakib2299.github.io/Enuexus_landing_page/

## Sections / Features

- Header navbar (Home, Company, Service, Intelligence, News, Contact)
- A full-width banner with a background image, a "Global Fraud Intelligence" headline and Contact Us / About Us buttons
- A company intro block with a "Read more" button
- "Our Services": four service boxes (Professional Service, Fraud Consulting, Analytical Service, Project Management)
- An "Intelligence" section with an image, a bullet list and a call-to-action button

## Built with

HTML5 · CSS3 (Flexbox)

## What I practised

- Flexbox layouts with percentage-based widths
- Full-bleed background images with `background-size: cover`
- Button hover states with transitions

## Run locally

Open `index.html` in a browser.
